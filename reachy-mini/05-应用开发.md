## Daemon 怎么跑一个 Python App

1. 控制台或 REST 发「启动」。
2. Daemon 用子进程跑 `python -u -m your_app.main`。
3. 应用拿到已经连上的 `ReachyMini` 和一个 `stop_event`。
4. 停止时 daemon 发 `SIGINT`，应用收尾。
5. 退出后 daemon 把机器人送回默认姿势。

约束：

- 同时只能跑一个 App。
- 应用不要自己再开一条硬件连接，用传进来的 `ReachyMini`。
- Wireless 上应用跑在 `/venvs/apps_venv/`。
- 子进程继承 daemon 的环境变量。密钥和地址更适合放在应用自己的设置页，而不是指望外部注入。

## 用助手生成骨架

不要手搓目录。CLI 会写好入口、HF 标签和包结构。

```bash
uv pip install reachy-mini
reachy-mini-app-assistant create my_app_name /path/to/destination --publish
# 或先只在本地：
reachy-mini-app-assistant create my_app_name /path/to/destination
```

| 模板 | 命令 | 何时用 |
|------|------|--------|
| 默认 | `reachy-mini-app-assistant create my_app .` | 大多数应用 |
| conversation | `... create --template conversation my_app .` | 要 LLM、语音、说话，自带音频管线、工具和动作融合 |

生成结果大致是：

```text
my_app/
├── index.html          # Space 落地页
├── style.css
├── pyproject.toml      # 含 entry point
├── README.md           # 必须带 reachy_mini_python_app 标签
└── my_app/
    ├── __init__.py
    ├── main.py
    └── static/         # 可选 Web UI
```

入口在 `pyproject.toml`：

```toml
[project.entry-points."reachy_mini_apps"]
my_app = "my_app.main:MyApp"
```

组名是 `reachy_mini_apps`。额外依赖写在这个文件里。

## 应用契约

实现 `ReachyMiniApp.run(reachy_mini, stop_event)`，循环里看 `stop_event`。`__main__` 里调用 `wrapped_run()`，这是 daemon 用 `python -m` 启动时的真正入口。`stop()` 由 SIGINT 间接触发。

高频动作用 `set_target`，一次性到位用 `goto_target`。

需要设置页时：

```python
class MyApp(ReachyMiniApp):
    custom_app_url: str | None = "http://0.0.0.0:8042"
```

设置后会起一个 FastAPI，提供包内 `static/`。Wireless 上从 `http://reachy-mini.local:8042` 打开；Lite 是 `localhost:8042`。不需要页面就设成 `None`。模板：<https://huggingface.co/spaces/pollen-robotics/reachy_mini_template_app>。

## 测试与发布

```bash
reachy-mini-app-assistant check /path/to/my_app
python -m my_app.main
```

在 Lite 上还可以 `uv pip install -e` 后开 daemon，到 <http://127.0.0.1:8000/> 里像用户一样点启动。Wireless 上对应的是机器人 IP 或 `reachy-mini.local:8000`。

发布需要有写权限的 Hugging Face token：

```bash
uv pip install --upgrade huggingface_hub
hf auth login
reachy-mini-app-assistant publish /path/to/my_app
```

创建时加了 `--publish` 的，之后直接 `git push`。要出现在商店里，README 前言必须有：

```yaml
tags:
  - reachy_mini_python_app
```

助手会自动加上。

参考实现（对话：VAD + LLM + TTS）：<https://github.com/pollen-robotics/reachy_mini_conversation_demo>。文档里的正式对话应用空间是 `reachy_mini_conversation_app`。

## 在 Wireless 上安装

控制台 Discover / Install 是正路。REST 把主机换成 `reachy-mini.local:8000`：

```bash
curl -X POST http://reachy-mini.local:8000/api/apps/install \
  -H "Content-Type: application/json" \
  -d '{"name":"<app_name>","source_kind":"hf_space","url":"https://huggingface.co/spaces/<user>/<app_name>"}'

curl http://reachy-mini.local:8000/api/apps/job-status/<job_id>
curl -X POST http://reachy-mini.local:8000/api/apps/start-app/<app_name>
curl -X POST http://reachy-mini.local:8000/api/apps/stop-current-app
curl http://reachy-mini.local:8000/api/apps/list-available/installed
curl http://reachy-mini.local:8000/api/apps/current-app-status
```

已经有 App 在跑时再启动，返回 `400 An app is already running`。没有 App 时停止，返回 `400 No app is currently running`。

开机自启（读 / 写 / 清除）：

```bash
curl http://reachy-mini.local:8000/api/apps/startup-app
curl -X PUT http://reachy-mini.local:8000/api/apps/startup-app \
  -H "Content-Type: application/json" -d '{"startup_app":"<app_name>"}'
curl -X PUT http://reachy-mini.local:8000/api/apps/startup-app \
  -H "Content-Type: application/json" -d '{"startup_app":null}'
```

机器人没有外网时（展会）：

```bash
scp -r /path/to/my_app pollen@reachy-mini.local:/tmp/my_app
ssh pollen@reachy-mini.local "/venvs/apps_venv/bin/pip install /tmp/my_app"
```

改完代码要重启 App 或 daemon。手动部署后若没吃到新代码，清掉 `__pycache__`。

## 日志与静默崩溃

Wireless 上应用的 stdout/stderr 进 journal：

```bash
ssh pollen@reachy-mini.local
sudo journalctl -u reachy-mini-daemon -f
sudo journalctl -u reachy-mini-daemon --since '5 min ago' | grep -v "uvicorn\|GET \|POST "
```

依赖没装进 `apps_venv` 时，导入失败可能看起来像「没启动、也没报错」。先在机器人上试导入：

```bash
ssh pollen@reachy-mini.local "/venvs/apps_venv/bin/python3 -c 'from my_app.main import MyApp'"
```

Daemon 状态坏了：`sudo systemctl restart reachy-mini-daemon`，等大约 30 秒再启动 App。

JS 网页应用连不上时：先在桌面控制台里用你的 Hugging Face 账号登录这台机器人，并确认没有另一个网页会话占着它。
