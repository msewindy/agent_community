## 装配之后的第一次联网

1. 打开 Reachy Mini。
2. 安装桌面程序 **Reachy Mini Control**：<https://hf.co/reachy-mini/#/download>。
3. 打开后点底部 **First time connecting...**（有的版本文案是 First time WiFi setup / First time connecting to your WiFi）。
4. 按向导先连上机器人自己的 Wi-Fi 热点，再把家里的 Wi-Fi 写进去。

刷机后的出厂热点（仅重刷或重置热点后会回到这个状态）：

- 网络名：`reachy-mini-ap`
- 密码：`reachy-mini`

## 系统更新

连上之后，在 Reachy Mini Control 的齿轮页进入 **System Updates**，有新版本就按屏幕安装。官方排障把「先更新、再关机等 5 秒后开机」当作几乎所有已知问题的第一步。

## 桌面控制台能做什么

- 看实时状态。
- Controller 页拖头部和天线。
- Expressions 页播放内置表情。
- 设置里做系统更新和 Wi-Fi。
- Applications 页进 Hugging Face Spaces，安装并启动 App（对话、游戏等）。

同一时间只能有一个 App 占着机器人。App 在跑时，不能再跑自己的 Python 脚本。

官方示例应用：

- Conversation：<https://huggingface.co/spaces/pollen-robotics/reachy_mini_conversation_app>
- Radio：<https://huggingface.co/spaces/pollen-robotics/reachy_mini_radio>
- Hand Tracker：<https://huggingface.co/spaces/pollen-robotics/hand_tracker_v2>
- 应用列表：<https://hf.co/reachy-mini/#/apps>

## 确认 daemon 活着

Wireless 上电后 daemon 已经在跑，不用在电脑上再启动一遍。浏览器打开：

<http://reachy-mini.local:8000/docs>

能看到 Swagger，就说明电脑和机器人在同一网络，并且 mDNS 解析成功。

## SSH 进机内树莓派

```bash
ssh pollen@reachy-mini.local
# 用户 pollen，密码 root
reachyminios_check
```

在机器人上跑 Python 时，用应用环境：

```bash
source /venvs/apps_venv/bin/activate
```

这时 `ReachyMini()` 会自动连本机 daemon，不必写成网络模式。官方给出的好处是延迟更低、不依赖外网；代价是 CM4 算力有限，也没有图形界面。

## 电脑上远程跑第一段脚本

电脑和机器人在同一局域网，本机已安装 `reachy-mini` 后：

```python
from reachy_mini import ReachyMini

with ReachyMini() as mini:
    mini.goto_target(antennas=[0.5, -0.5], duration=0.5)
    mini.goto_target(antennas=[-0.5, 0.5], duration=0.5)
    mini.goto_target(antennas=[0, 0], duration=0.5)
```

构造函数会区分 Lite 和 Wireless，在 localhost 和网络之间自动选择。需要强制时：

```python
ReachyMini(connection_mode="localhost_only")  # 或 "network"
```

远程取画面和音频时，WebRTC 客户端目前以 Linux 为准。Windows 上若只做运动控制，REST 或自动连接通常就够；要稳定看画面，把脚本放到机器人上跑，或改用浏览器 JS SDK。
