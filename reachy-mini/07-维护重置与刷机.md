日常问题用控制台更新和重启。蓝牙重置和刷镜像都是维护手段；刷镜像会恢复出厂，官方明确说大多数人不需要。

## 蓝牙：重置热点、重启 daemon、软件重置

优先用 Reachy Mini Control（电脑蓝牙要开着）：连接页底部进入首次 Wi-Fi 向导，再点 **Try the Bluetooth Console**。控制台里可以重置热点、看网络状态。

没有桌面程序时：

- 支持 Web Bluetooth 的浏览器（Chrome、Opera、Edge）打开 <https://pollen-robotics.github.io/reachy_mini/>。
- 或手机上的 nRF Connect，扫描设备名 **ReachyMini**，连上后进 Unknown Service，向 WRITE 特征写命令。

任何命令之前都要先发 PIN。PIN 是序列号**最后 5 位**。例如序列号以 `4918400018` 结尾，就发 `PIN_00018`。

| 命令 | 作用 |
|------|------|
| `STATUS` | 查状态 |
| `PIN_<5 位>` | 先鉴权 |
| `CMD_HOTSPOT` | 重置 Wi-Fi 热点 |
| `CMD_RESTART_DAEMON` | 重启 daemon |
| `CMD_SOFTWARE_RESET` | 重装出厂 daemon。机器人会重启，大约 5 分钟后才能再连 |

nRF Connect 写的是这些字符串的十六进制（文档给了 `PIN_00018` 等示例）。控制台和网页工具可以直接发文本，不必手算十六进制。

`CMD_SOFTWARE_RESET` 也是「装了试验分支的 daemon、想回到出厂」的回退办法。

## 刷 ReachyMiniOS（专家）

会清空 CM4。只在系统起不来、而且排查无效时做。镜像与 `.bmap`：

<https://github.com/pollen-robotics/reachy-mini-os/releases>

工具：

- 让 eMMC 变成 U 盘：Raspberry Pi `rpiboot`。Linux/macOS 按 <https://github.com/raspberrypi/usbboot> 编译；Windows 用 <https://github.com/raspberrypi/usbboot/raw/master/win32/rpiboot_setup.exe>。Windows 要选 **rpiboot-CM4-CM5 - Mass storage Gadget**，不要选 CM/CM2/CM3 那一个。
- 写入：Linux / macOS 优先 `bmaptool`（比 Imager 快很多）。Windows 用 [Raspberry Pi Imager](https://www.raspberrypi.com/software/)，设备选 Raspberry Pi 4，系统选自定义镜像，磁盘一般是 `RPi-MSD-0001`。

步骤要点：

1. 机器人完全关机。
2. 先启动 `rpiboot`，让它等设备。Linux/macOS：`sudo ./rpiboot -d mass-storage-gadget64`。窗口不能关。
3. 头部 PCB 开关拨到 **DOWNLOAD (SW1)**。
4. USB 线插文档图里的 **USB2**。
5. 开机。`rpiboot` 跑完后，eMMC 会出现成一块磁盘。
6. 先卸载 `bootfs` / `rootfs`，再写入。macOS 用 `diskutil unmountDisk`，写入设备必须是 `/dev/rdiskX`（带 `r` 的原始设备）。
7. 关机，开关拨回 **DEBUG**，拔掉 USB，再开机。

验证：电脑连上 `reachy-mini-ap` / `reachy-mini`，然后：

```bash
ssh pollen@reachy-mini.local
reachyminios_check
```

成功时输出 `Image validation PASSED`。随后要重新做 Wi-Fi 配置和系统更新。

## 正常启动开关

热点完全不出现、树莓派像没启动时，先看头部板上的开关是不是被拨到了 DOWNLOAD。必须在 **DEBUG**。位置对了仍然没有热点，才考虑上面的刷机。
