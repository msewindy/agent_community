## 2. 架构决策（仍生效）

| ID | 决策 | 实现含义 |
|----|------|----------|
| **D1** | 学情主轴 = `knowledge_point_id` | `gap_map` 以 KP 为键；错因码为可选叠加 |
| **D2** | KP 权威由人确认 | `/kp-review`、catalog 写入受审核约束 |
| **D3** | 归类自动 + 家长可纠 | `classify_photo` / inbox；订正 UI 仍不完整（见 03） |
| **P7** | 流程非硬编码 | 无「拍照必入库」状态机；意图驱动编排 |
| **AP6** | 学情轨 ≠ M2 画像轨 | `student_data/` 与 memory 分离 |

设计原则摘要：对话主线程 · 知识点坐标系 · 权威/自动分离 · 证据优先（仅约束掌握结论） · 能力分层可选。

## 5. 核心模块与数据流

### 5.1 模块全景（逻辑）

```text
内容权威          学习引擎              交互入口
─────────        ──────────            ────────
kp_catalog   →   gap_map / attempt  ←  8771 chat / ASR / vision
question_bank→   questions_suggest
wiki (教案)  →   explain_kp
photo_triage →   inbox / classify
                 parent_report     →  8770 panel
```

### 5.2 关键数据路径

| 数据 | 路径（相对仓库根） | 说明 |
|------|-------------------|------|
| 学情/attempt/gap | `student_data/{student_id}/` | **不入 git** |
| 题库 | `agent_platform/learning/question_bank/questions.db` | SQLite；种子 JSON 可导入 |
| KP 目录 | `agent_platform/learning/catalog/kp_catalog.json` | 批准入库可变更 |
| Wiki 讲解 | `wiki_data/raw/kp/*.md` | 多骨架，可运营补全 |
| 待归类 inbox | `student_data/_question_inbox/` · photo inbox | 家长 `/exercises` |
| 课堂活动 | `student_data/_classroom_activities/` | 不进自动推题 |
| 配置 | `agent_platform/config/student_learning.yaml` 等 | 改后需重启 8771 |

可选：`STUDENT_JARVIS_DATA_ROOT` 覆盖学情根目录。

### 5.3 主数据流（端到端）

**对话练题（设计路径）**

```text
孩子消息 → Hermes → questions_suggest → question_get
  → 作答 → attempt_submit → attempts/*.json + gap_map
  → 8770 learning-dashboard 可见
```

**讲新课**

```text
讲新课意图 → teach_preflight（可 set_learning_focus）
  → explain_kp / Wiki → 对话讲解
  → （设计）应记学习活动；封版尚未产品化 Activity
```

**拍照入学情**

```text
上传 → /api/vision/understand → Vision 卡片
  → Agent 判意图 → classify_photo
  → 高置信入 gap / 中待确认 / 低入 inbox → 8770 处理
```

**内容入库**

```text
.pdf / .kp.md → 解析器或审核 → KP→catalog · 题→SQLite · 难例→inbox
```

## 6. Agent 与工具实现

### 6.1 运行时

| 组件 | 说明 |
|------|------|
| Hermes | Agent 循环、tool_call、插件 |
| `HermesBridge` | 8771 调用 Hermes（流式/非流式） |
| `agent-student` | 学习工具 + pre_llm hook |
| 其它插件 | memverse / wiki / calibration / proactive / perception… |

### 6.2 主要学习工具（I2）

| 工具名 | 作用 |
|--------|------|
| `learning_catalog_lookup` | catalog 闭集查单元 |
| `learning_focus_set` | 持久化当前学习单元 |
| `explain_kp` | 讲解知识点（Wiki raw） |
| `questions_suggest` | 按单元/KP 实时选题 |
| `question_get` | 取题面（不含答案） |
| `attempt_submit` | 题库题判分入学情 |
| `attempt_submit_freeform` | 无题号真实题入学情 |
| `gap_map_query` | 查薄弱/掌握 |
| `classify_photo` | 拍照归类分流 |
| `student_context_get` | 读当前情境与 session_stats |
| `study_plan_generate` 等 | 微计划（产品验证弱） |

提示词契约：`agent_platform/learning/prompts.py`（意图编排、Focus 规则、AnswerGate）。

### 6.3 感知与语音

| 能力 | 实现 | 配置/依赖 |
|------|------|-----------|
| 图像理解 | DashScope 兼容 API · `qwen3-vl-plus` | `perception.yaml` · `DASHSCOPE_API_KEY` |
| 语音识别 | DashScope Paraformer · `POST /api/asr` | `dashscope_asr.py` · ffmpeg · 前端按住说话 |
| 朗读 | edge-tts | 无需 DashScope Key |
| 对话 LLM | DeepSeek `deepseek-chat` | `voice.yaml` · `DEEPSEEK_API_KEY` |

说明：ASR 与 VLM **共用** `DASHSCOPE_API_KEY`，**不是**同一模型。

## 7. 双端 API 要点

### 7.1 孩子端 8771

| 路径 | 作用 |
|------|------|
| `GET /` | 聊天页（HTML **按请求热加载**） |
| `GET /health` | bootstrap + asr 就绪 |
| `GET /api/chat/welcome` | 欢迎语 + `learning_context_line` |
| `POST /api/chat` · `/api/chat/stream` | 对话（回复经 `sanitize_student_reply`，含剥离 Hermes 运维摘要） |
| `POST /api/asr` | 语音→文字 |
| `POST /api/tts` | 文字→语音 |
| `POST /api/vision/understand` | 拍照理解 |

默认学生：`student_learning.yaml` → `hermes.default_student_id`（`g2-stu-01`）。

### 7.2 家长端 8770

| 路径 | 作用 |
|------|------|
| `/` | 学情总览（`learning-dashboard`） |
| `/learning-detail` · `/weekly-report` | 详情 / 周报 |
| `/kp-catalog` · `/kp-review` | 浏览 / 审核知识点 |
| `/exercises` | 习题处理 + 待归类 |
| `/api/students/{id}/learning-dashboard` | 学情 JSON（**基于 attempt/gap**） |

## 9. 实现与设计的已知缝隙（架构视角）

| 缝隙 | 说明 |
|------|------|
| Activity 未落地 | 设计有「学习活动」；实现无独立账本 → 听讲不进家长进度（等 R6 拍板） |
| 练题工具合规 | T5 **工程已合入**；仍靠试用抽查（口头绕过风险未归零） |
| Focus 编排偏默认 u01 | 「学某科」常从第一单元开讲；需提示词/Focus 先问或接续（窗口期轨 E） |
| 看图题无图通道 | 题库 stem 无配图字段；孩子端气泡纯文本 → 依赖插图的 exact 题不应推送 |
| 掌握订正不完整 | D3/Q4 设计有；gap 级 manual_override 产品弱 |
| 中档待确认 UI | 后端语义有；前端重操作偏 inbox |
| 内容深度 | 非试点多零题/薄 Wiki；见 [03](./03-封版内容与残留问题.md) 内容快照 |
| 每轮 Hermes 冷启动 | `hermes chat` 子进程加载插件+MCP，叠加首包 LLM，首轮易 &gt;60s |

细节与封版边界见 [03](./03-封版内容与残留问题.md)；窗口期动作见 [窗口期执行方案](./窗口期四项-执行方案.md)。
