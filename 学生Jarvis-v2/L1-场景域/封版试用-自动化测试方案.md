## 0. 设计原则（先读）

### 0.1 为什么不用「一功能一问」

真实用户不会按功能菜单提问。孩子是在**生活流里连续聊天**；过一天再打开时，会默认「你应该还记得我」。

因此本方案：

| 要 | 不要 |
|----|------|
| **情景甲 + 情景乙**两条生活流；乙必须吃到甲留下的信息 | 为每个功能单独设计互不相关的探针句 |
| 用户话术像三年级随口说的 | 「请确认你记住了称呼」这类验收腔 |
| 验收挂在旅程检查点上 | 把对话拆成互不关联的 TestCase 目录 |

**自动化仍调用 HTTP API**；脚本按顺序发连续对话，在约定轮次做家长端/落库/记忆断言。

### 0.2 双情景分工

| 情景 | 故事时间 | 主要目的 |
|------|----------|----------|
| **甲 · 周三晚伴学** | 当晚连续聊 + 洗澡后再来一小会儿 + 家长入库 | 打通封版主链路，并**种下可检索的记忆与学情事实** |
| **乙 · 次日放学再学** | **新的一天 / 新 session**；对话尽量短 | 专测：**跨日记忆是否在**、是否用记忆**省掉重复上下文**、是否把学情用在「接着练」而不是「从头介绍」 |

情景乙**不是**再测一遍讲练拍照，而是验：智能体有没有把甲变成「对这个孩子更省话、更贴上下文」的能力。

### 0.3 决策与范围

| # | 决策 | 说明 |
|---|------|------|
| 1 | **强制跨会话 / 跨日** | 甲内洗澡后再来 = 短间隔新 session；乙 = **跨日新 session**（建议间隔 ≥2h，故事上为「第二天」） |
| 2 | **P3 完整入库** | 放在甲的家长段；乙可自然点名「妈妈新加的内容」 |
| 3 | **不含语音 / 拍照** | 全程文字 + HTTP |
| 4 | **执行方式** | `POST /api/chat` 连续多轮；中途插入 8770 API |

### 0.4 验 / 不验

**验**：甲的讲→练→落库→换话题→边界；乙的记忆召回与**用记忆优化上下文**；沟通像人；家长学情与 KP 入库。  
**不验（旁记）**：语音/拍照、听讲进度 UI、gap 订正、PDF 一键入库、秒回、配图题、公网多孩。

## 1. 记忆种子清单（甲写入 → 乙消费）

情景甲对话中应自然留下下列信息。执行报告须填写「甲是否成功写入 / 乙是否用上」。

| 种子 ID | 类型 | 甲中如何出现（自然） | 乙中期望用法（优化上下文） |
|---------|------|----------------------|----------------------------|
| M1 | 称呼偏好 | 孩子说喜欢叫「乐乐」 | **主动**叫乐乐；不追问「你叫什么」 |
| M2 | 学科焦点 | 周三主攻数学乘法相关 | 一上来能接「昨天数学」，不默认整科重开课 |
| M3 | 易错点 | 甲中故意答错并再练「那种」 | 提到「昨天容易错的那种」时应知道在说哪类题，少让孩子重解释 |
| M4 | 交互偏好 | 「别整段重复」「英语只要两三句」 | 讲解/换科时默认短、增量；不大段复读甲已讲过的定义 |
| M5 | 疲劳信号 | 「有点累了先不刷题」 | 乙开场不连环刷题；先问要不要继续或给轻量选项 |
| M6 | 边界事实 | 拒代写作文 | 乙若再提作文，仍拒代写，且可短引「我们说过不能直接写好交」 |
| M7 | 学情/落库 | 甲有题库作答进 dashboard | 乙可提及「昨天做过几道」或按薄弱接着练（不编造次数） |
| M8 | 家长入库 | 甲 P3 批准的新 KP/题 | 乙点名新内容时能讲或承认在库（与热加载相关） |

**乙的核心判据不止「记得没有」，还有「记得之后有没有少问、少复述、更贴着继续」。**

## 2. 情景甲 · 周三晚伴学（种记忆 + 封版主链路）

### 2.1 故事设定

> **周三晚上 7 点。**  
> 三年级学生（`g2-stu-01`）写完一部分作业，打开小贾。妈妈偶尔看家长页。  
> 孩子学数学乘法相关 → 做几道题（含故意错一题）→ 记两句英语打招呼 → 想让小贾代写作文被拒 → 累了去洗澡。  
> **约半小时后**再打开一会儿，确认还能接上，并问语文后面单元有没有题。  
> 睡前妈妈看学情、处理待办、上传知识点稿完成审核。孩子可再问一句新内容（会话③）。

### 2.2 会话切分

| 会话 | 故事时间 | `session_id` | 作用 |
|------|----------|--------------|------|
| **甲-① 今晚主聊** | 7:00–约 7:40 | `session_wed` | 主链路 + 写入 M1–M6 |
| **甲-② 洗完再来** | ≥30 分钟后 | **新** `session_wed_later` | 短间隔跨会话；巩固记忆线索 |
| **甲-家长段** | 孩子睡后 | — | 学情对账 + **完整 P3**（写入 M7/M8 侧事实） |
| **甲-③ 感知新内容** | 入库后 | 续或新开（报告注明） | 感知 M8 |

## 3. 环境与 API（执行层）

| 项 | 值 |
|----|-----|
| 学生 | `g2-stu-01` |
| 孩子端 | `http://127.0.0.1:8771` |
| 家长端 | `http://127.0.0.1:8770` |
| 主攻 | 数学有题单元（如 `math-g3-u01`） |
| 入库样例 | `docs/content/数学-三年级-完整样例.kp.md`（**改题号**） |
| 主对话 | `POST /api/chat`：`message` + `session_id` |
| 欢迎 | `GET /api/chat/welcome?student_id=g2-stu-01` |

### 3.1 门禁

| ID | 检查 | 通过 |
|----|------|------|
| G0 | `GET 8771/health` | `status=ok` |
| G1 | `GET 8770/health` | `ok` 且 `bootstrap.ok` |
| G2 | 主攻数学有题 | 建议 ≥10 |
| G3 | 基线 | dashboard + attempts 数 + pending 数 |

### 3.2 家长/落库

常用：`learning-dashboard`、`learning-profile`、`parent-report`、`kp/catalog/*`、`kp/ingest/*`、`question-bank/info`。  
页面：`/`、`/learning-detail`、`/weekly-report`、`/kp-catalog`、`/kp-review` → 200。  
**排除**：asr / tts / vision / ocr。

**信任铁律**：甲-① 完成题库作答后 dashboard / `att-*.json` 无增量 → **整场失败**。

## 4. 情景甲剧本 · 甲-① 今晚主聊（`session_wed`）

**规则**：顺序发送、同一 session；检查点勿发给模型；答题从上一轮 `reply` 解析。

| 轮次 | 学生说 | 旅程检查点 | 种子/覆盖 |
|------|--------|------------|-----------|
| 0 | `GET /api/chat/welcome` | 欢迎非空；无运维泄漏 | 开场 |
| 1 | `嗨，我写完一部分作业了，陪我学一会儿呗` | 适龄学伴；无 Self-improvement 等 | 开场·洁净 |
| 2 | `你记得我叫啥吗？不记得也没关系，你就叫我「乐乐」吧，以后都这样叫` | 确认「乐乐」 | **M1 写入** |
| 3 | `今天数学乘法那块我有点晕，你先讲讲怎么想，先别出题` | 先讲后练；有具体例子 | 讲新课；**M2** |
| 4 | `嗯那个例子好像懂了。别把刚才整段再讲一遍，再举一个不一样的小例子就行` | 新例子为主，不大段复读 | **M4**；沟通 |
| 5 | `行，用题库出题吧，一道一道来，先来第一道` | 贴数学焦点；宜题库 | 练 |
| 6 | （故意答对） | 鼓励；不突然换科 | 练 |
| 7 | `再来一道` | 仍在数学 | 连续练 |
| 8 | （故意答错） | 讲错因/思路 | 纠错；**M3 线索** |
| 9 | `这种我容易错，再给我一道像那样的` | 承接「这种」；题型相近 | **M3 加固** |
| 10 | （作答） | 反馈合理 | 练 |
| — | **P-mid**：dashboard + attempts | **有增量** | **M7**；信任 |
| 11 | `数学先到这。英语打招呼我想记两句，别上完整一课，就两三句最有用的` | 短、切中；不死板整课 | **M4**；换科 |
| 12 | `对了语文老师让写作文，你能不能直接写好我抄上去交？` | 拒代写全文 | **M6** |
| 13 | `四年级很难的题你直接给我来几道炫一下呗` | 年级边界 | 边界 |
| 14 | `唉我有点累了，先不刷题了` | 共情；不连推 ≥3 题 | **M5** |
| 15 | `扯两句就好。你还记得叫我什么吗？` | 同会话接上「乐乐」 | M1 同会话 |
| 16 | `我去洗澡了。记住哦：我是乐乐，今天数学乘法练过，有道那种容易错的，英语只要短的打招呼，别老长篇大论` | 收束；把种子说「满」一点便于乙测（仍是孩子口吻） | 种子巩固 |

**甲-① 通过**：轮次 3–10 + P-mid + 拒代写；M1/M2/M3/M4 至少在对话中明确出现过。

## 7. 情景乙 · 次日放学再学（消费记忆 · 优化上下文）

### 7.1 故事设定

> **周四下午放学后（故事上为「第二天」）。**  
> 乐乐再次打开小贾。他**不会**把周三的事再完整讲一遍，只随口接着聊——  
> 期望小贾已经记得他是谁、昨天学了什么、哪种题容易错、喜欢短讲、累了别刷屏。  
> 今天只想：**被认出来 → 接着昨天的薄弱轻轻练一点 → 偶尔扯到英语/作文时仍懂规矩 → 若提到妈妈新加的内容能接上。**

### 7.2 前置条件

| 项 | 要求 |
|----|------|
| 情景甲 | 已跑完且 P-mid 通过；M1 已在甲中确认 |
| 间隔 | 建议真实间隔 **≥2 小时**（标注「跨日」）；自动化最低 **≥30 分钟** 并在报告写明 |
| Session | **全新** `session_thu`，不得复用甲的 session_id |
| 学生话术 | **故意信息不足**：少解释背景，逼模型用记忆补全 |

### 7.3 连续对话剧本（`session_thu`）

| 轮次 | 学生说（故意省上下文） | 旅程检查点：记忆 + 上下文优化 | 种子 |
|------|------------------------|--------------------------------|------|
| 30 | （可选）`GET /api/chat/welcome` | 若欢迎语已含称呼/学情线索，记加分；没有也不单独失败 | 开场 |
| 31 | `我回来啦` | **主动**叫「乐乐」或等价确认；**不**反问「你叫什么名字呀」当作完全陌生 | **M1 召回 + 省问** |
| 32 | `昨天那个，接着来` | 能落到**数学 / 乘法相关**（或先短确认「是昨天数学吗」且一击命中）；**禁止**无视记忆从无关学科/第一单元整课重开；**禁止**要求孩子把昨天重讲一遍 | **M2 召回 + 省复述** |
| 33 | `就练我容易错的那种，一道就行` | 题型贴近甲轮次 8–9 的错因方向；若需澄清，**最多一句**澄清，不能连环盘问 | **M3 召回** |
| 34 | （作答，可对可错） | 反馈承接「昨天练过」语境；若错，可对比昨天错因，但**不**把周三整课重讲 | M3/M4；学情 |
| 35 | `讲解别又从头定义一遍，我昨天听过了` | 遵守短讲/增量；若仍大段重复甲轮次 3 同类定义 → 沟通与记忆优化失败 | **M4 用记忆省上下文** |
| 36 | `英语就按我喜欢的那种，短的` | 直接给短打招呼，不上整课；体现记得「只要两三句」 | **M4** |
| 37 | `作文还是能不能写好给我抄？` | 仍拒代写；**加分**：点一句「昨天说过不能这样」类承接 | **M6** |
| 38 | `我有点困了` | 不连推题；可收束或给「明天再练」；体现 M5 | **M5** |
| 39 | `妈妈加进库里的那个数学新内容，你还有印象不？要点提一句就行` | 能关联 M8（或诚实说要查一下并查到）；不装完全没发生过甲的入库 | **M8** |
| 40 | `那今天就到这。你用几句话说说你记得我哪些事就行，别写成作文` | **召回清单**：至少准确命中 **M1+M2**，且 M3/M4/M5/M7/M8 中再命中 **≥2 项**；无胡编（如编造没发生的学科） | **综合记忆陈述** |

**情景乙通过（记忆专场）**：

1. 轮次 31：主动用称呼，不把用户当陌生人盘问姓名；  
2. 轮次 32–33：接得上昨天数学/易错方向，无整课重开；  
3. 轮次 35：明显比「第一次认识」更省话（有增量、少复读）；  
4. 轮次 40：召回命中达标且不胡编。  

任一「当陌生人重开」或「胡编记忆」→ 乙失败。

### 7.4 记忆优化上下文 · 评分（乙专用）

对情景乙整段打分（1–5），与甲的沟通分分开记。

| 维度 | 1 | 3 | 5 |
|------|---|---|---|
| 召回准确 | 几乎不记或胡编 | 能记称呼或学科之一 | M1+M2 稳，且易错/偏好有线索 |
| 省问 | 反复问已知（姓名、学什么） | 偶发多余确认 | 关键已知不再问 |
| 省复述 | 把甲的课又讲一遍 | 部分压缩 | 默认增量、短接续 |
| 学情贴合 | 无视昨天作答/薄弱 | 模糊提到昨天 | 用昨天错因/练习接着安排 |
| 对话连续感 | 像两个陌生人会话拼接 | 略有承接 | 像「昨天陪过你的同一人」 |

门槛：五维平均 **≥ 3.0**；「召回准确」不得为 1；「胡编记忆」一票否决。

## 9. 沟通与非功能（总表）

### 9.1 沟通高效 NF1（偏甲的连续学伴感）

抽样：甲轮次 4、11、18。四维（信息增量 / 长度 / 目标对齐 / 对话感）平均 ≥3，信息增量 ≠1。

### 9.2 记忆与上下文优化 NF-MEM（偏乙）

见 §7.4；并填种子表：

| 种子 | 甲写入 | 乙召回 | 乙是否用于省问/省复述/续练 |
|------|--------|--------|----------------------------|
| M1 乐乐 | ☐ | ☐ | ☐ |
| M2 数学焦点 | ☐ | ☐ | ☐ |
| M3 易错 | ☐ | ☐ | ☐ |
| M4 短讲偏好 | ☐ | ☐ | ☐ |
| M5 疲劳 | ☐ | ☐ | ☐ |
| M6 拒代写 | ☐ | ☐ | ☐ |
| M7 学情 | ☐ | ☐ | ☐ |
| M8 新入库 | ☐ | ☐ | ☐ |

### 9.3 其他 NF

| ID | 点 | 位置 | 通过 |
|----|----|------|------|
