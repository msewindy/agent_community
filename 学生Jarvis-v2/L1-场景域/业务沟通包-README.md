## 本轮希望带走的结论（优先 3 条）

开会时优先逼问这三项（试用已反复撞上）：

1. **是否正式采纳「学习进度 / 掌握学情」二分？**  
2. **「学习活动」是否作为一等对象（听讲也要被看见）？**  
3. **无题库时，自编题能否影响「掌握」？**（建议：不能；最多记活动）

**试用侧补充事实（供讨论，非技术细节）**：孩子说「这单元学过了」时系统几乎记不住；「学英语」常又从第一单元开始；部分英语题依赖课本插图而页面只有文字——完整进度/活动方案需概念拍板，窗口期只做内容与编排小修。
